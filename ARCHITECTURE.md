# ARCHITECTURE · v1.2

- `index.html`: автономный статический сайт и базовый экранный роутер. Содержит учебные данные, три исходных урока, профиль `samorazvitie_site_v1` в `localStorage`, аудиостудию и импорт/экспорт.
- `learning-v12.js`: **отдельный модуль** самостоятельных ответов, лаборатории кейсов, проверки аргументов, карты знаний, списка литературы, повторения и сохранения аудиопозиции. Ключ `samorazvitie_learning_v12`.
- Базовый `localStorage` v1 и все существующие отметки сохранены. Данные нового модуля вложены в JSON-экспорт в поле `extensions`; импорт/сброс синхронизируются событиями.
- `audio-player` живёт **вне** перерисовываемого `#main`: при навигации аудио не уничтожается. Бинарный MP3 остаётся на устройстве и не сохраняется сервером.
- Навигация: базовые hash-маршруты + дополнения модуля v1.2.
- Тесты: `scripts/verify-site.mjs` и `tests/browser-smoke.mjs` (Chromium). Workflow проверяет PR, публикует `main` и проверяет публичный HTTPS-ответ.
- Публичный код, публичный доступ по ссылке. `robots noindex` не реализует авторизацию.
- Сайт не делает платных API-вызовов, не содержит ключей, модели речи и удалённой базы данных.

**Технический долг:** базовый `index.html` всё ещё содержит большой встроенный JS/CSS. В следующем этапе выделить данные и роутер в отдельные тестируемые модули, не разрушая сайт ради рефакторинга.
