# ARCHITECTURE · подтверждённое устройство

- `index.html`: автономная HTML/CSS/JavaScript-версия. Нет npm-зависимостей и внешних JS/CSS.
- Данные: редакционные уроки, 18 разделов конспекта, задания и ответы встроены в страницу. В будущем вынести контент в типизированные отдельные файлы.
- Навигация: hash-маршруты. Работают без серверной маршрутизации.
- Состояние: `localStorage` конкретного браузера. Есть экспорт/импорт JSON; нет аккаунта и облачной синхронизации.
- Аудио: проигрывается только файл, выбранный пользователем локально. Исходный MP3 не публикуется.
- CI: `scripts/verify-site.mjs` проверяет структуру и синтаксис, `.github/workflows/pages.yml` публикует статический сайт на GitHub Pages после коммита в main.
- Приватность: репозиторий и веб-страница публичные. `noindex` не ограничивает доступ. Не загружать персональные данные и защищённые источники.
- ИИ: пока отсутствует. Позднее требует server-side API, контроля расходов, источников и прав доступа.
