## Реализовано в ветке
- Постоянный аудиоплеер, локальное сохранение позиции и скорости, отсутствие сброса при переходах.
- Перенос заголовков на узком экране; вместо «Освоен» показывает «Прочитано».
- Самостоятельные ответы (80+ символов), критерии проверки и отдельная запись самопроверки только после правильного кейса.
- 3 бизнес-кейса, проверка аргументов, начальная карта знаний, библиография источников с оговорками.
- Дополнительное интервальное повторение, включение данных модуля в локальный экспорт/импорт.
- GitHub Actions с Node.js 24, браузерный Chromium-тест 320/390/768/1440 px, аудио, упражнения и локальное сохранение.
- Постоянный отчёт [docs/AUDIT_2026-11-15.md](docs/AUDIT_2026-11-15.md).
