# Саморазвитие · личная учебная платформа

**Сайт:** https://grobovchik797.github.io/self-development-platform/

**GitHub:** https://github.com/Grobovchik797/self-development-platform

> Это статическая персональная образовательная платформа. Доступна каждому, кто получил ссылку. Поисковикам передаётся `noindex`, но **это не пароль и не полноценная приватность**. Не размещайте личные или защищённые материалы в публичном репозитории.

## Что уже работает

- Главная, каталог с поиском, книга, практика, повторение, заметки, настройки.
- Три развёрнутых урока по теме социальных связей, каждый с режимами «За 2 минуты», «Разобраться», «Копнуть до дна».
- 18 разделов **19-страничного конспекта** «Социальные связи» и учебные кейсы с обратной связью.
- Локальная аудиостудия: пользователь выбирает MP3 **со своего устройства**, исходная запись не хранится на сервере.
- Закладки, отметки прохождения, расписание повторения, заметки, экспорт/импорт JSON.
- Тёмная и светлая темы, адаптация под телефон.

## Источник и ограничения

Исходный учебный материал: предоставленный владельцем конспект «Социальные связи» (19 страниц, Зачёт, 14.11.2026). Предоставлен также аудиофайл около 3:19:36, но **автоматическая расшифровка не выполнена**. Уроки являются авторской образовательной интерпретацией конспекта, не полным разбором оригинального текста и не независимой научной экспертизой. Чужие PDF/MP3 в репозиторий **не загружаются**.

Прогресс хранится в `localStorage` браузера, без учётной записи, синхронизации и сервера. Перед очисткой браузера сделайте экспорт JSON в настройках.

## Технически

- `index.html`: автономный HTML/CSS/JS-сайт без внешних библиотек.
- `scripts/verify-site.mjs`: проверка структуры, учебных материалов и JS-синтаксиса.
- `.github/workflows/pages.yml`: автоматические проверки PR и публикация `main` на GitHub Pages.
- `PROJECT.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `DECISIONS.md`, `CONTENT_GUIDE.md`, `PROGRESS.md`: документация и статус реализации.
- `DEPLOY.md`: одноразовая настройка GitHub Pages.

Локальная проверка: `node scripts/verify-site.mjs`. Открывать сайт для просмотра можно по обычному Pages-адресу после успешной публикации.
