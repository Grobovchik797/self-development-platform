## Версия v1.2

- Главная, поиск по каталогу, 3 авторских урока по социальным связям, 18 разделов вторичного конспекта книги, три глубины изучения.
- Браузерная аудиостудия: локальный MP3, постоянный нижний плеер, сохранение позиции и скорости при переходах; после перезагрузки браузера файл надо выбрать повторно (файл не передаётся на сервер).
- Заметки, закладки, отдельная отметка **«Прочитано»**, локальный экспорт/импорт JSON, темы оформления.
- Самостоятельный текстовый ответ и критерии: для отметки самопроверки нужен написанный ответ от 80 символов **и** правильный ответ на исходный кейс. Это самоотчёт, не автоматический экспертный экзамен.
- **Бизнес-лаборатория:** 3 вымышленных ситуации с обратной связью и вариантами решений.
- **Проверка аргументов:** сильный тезис, возможное возражение, необходимые проверки и статус доказательств.
- **Карта знаний:** начальная интерактивная карта связей в виде карточек со ссылками на существующие разделы.
- Независимый список библиографических ссылок на исследования доверия, слабых связей и обучающих практик. Ссылки НЕ подтверждают целиком конспект книги.
- Обновлены GitHub Actions Node 24 и включён браузерный smoke-тест (320/390/768/1440 px, аудио, ответы, прогресс).
- Публичная страница запрашивает `noindex`. **Она не защищена паролем.** Любой человек с адресом имеет доступ к публичному содержимому. Персональные данные и сторонний MP3/PDF не публикуются.

## Проверка и разработка

Сайт статический, без сборки и внешних библиотек. `index.html` + `learning-v12.js`.

- Статический тест: `node scripts/verify-site.mjs`.
- Браузерный тест: `npm install --no-save playwright && npx playwright install chromium && node tests/browser-smoke.mjs`.
- CI GitHub проверяет изменения, затем публикует `main` через GitHub Pages и делает HTTP-запрос к реальному адресу.

## Источники и ограничения

Первая серия уроков основана на предоставленном **19-страничном конспекте** «Социальные связи», 14.11.2026, а не на полном изучении оригинала. Аудиокнига 03:19:36 пока не расшифрована. Утверждения о российских деловых связях, особенно культурные обобщения, требуют отдельной проверки.

Локальный прогресс зависит от браузера. Используй экспорт в настройках для копии перед сменой устройства или очисткой данных.

Серверной системы пользователей, ИИ-преподавателя, расшифровки MP3 и облачной синхронизации пока нет.
