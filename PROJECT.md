# PROJECT · Саморазвитие

## Цель
Персональная учебная платформа, где знания превращаются в понимание, аргументированное мышление и практику.

## Текущие границы
Веб-приложение в одном статическом HTML-файле. Реализованы 3 самостоятельных урока и разбор 18 разделов **конспекта** книги о социальных связях. Восемь тематических направлений остаются продуктовой дорожной картой, а не заполненной библиотекой.

## Критерий ближайшей готовности
Сайт открывается по одному постоянному HTTPS-адресу GitHub Pages, работает на мобильном и компьютере, основные сценарии проходят тесты.

## Не реализовано
Серверная авторизация, синхронизация данных, полный транскрипт аудиокниги, независимая проверка всех тезисов, настоящий ИИ-агент.

Полная исходная спецификация хранится в источниках владельца проекта и не зеркалируется автоматически в открытый репозиторий.
