## 2. Что означают значки GitHub Actions на присланном скриншоте

- **Зелёный кружок с галочкой**: задание `verify` / `deploy` завершилось успешно.
- **Жёлтый треугольник (warning)**: версии `actions/checkout@v4`, `actions/setup-node@v4` и Pages-action используют устаревший runtime Node.js 20. GitHub запускает их на Node.js 24 совместимым способом. Это не ошибка публикации, но повод обновить зависимости.
- **Кружок с буквой i (notice)**: GitHub переносит `ubuntu-latest` с Ubuntu 24.04 на Ubuntu 26.04. Это уведомление о смене инфраструктуры, а не авария.
- **Путь исправления:** использовать официальные новые версии Actions на Node 24, закрепить runner на Ubuntu 24.04 в первом переходе; в будущем проверить совместимость с Ubuntu 26.04. PR с изменениями обязан пройти CI и проверку живого HTTPS.

## 4. Продуктовые выводы

**Сильная сторона:** одна тема про социальные связи уже объединяет учебный текст, критику, практический кейс, книгу, заметки и повторение.

**Недостаток, который важнее количества страниц:** первоначальный «прогресс» был количеством нажиманий, а не доказанным пониманием.

Рекомендованная образовательная последовательность:

1. Кратко понять механизм, а не определение.
2. Объяснить своими словами до просмотра подсказки.
3. Решить **другой**, похожий на реальный, кейс.
4. Сравнить ответ с явно опубликованными критериями.
5. Вернуться к материалу через интервал.
6. Оценить сильный контраргумент и связь с соседними понятиями.

Уточнение: свободный текст пока **не анализируется ИИ**. Даже корректно заполненная самопроверка остаётся самоотчётом пользователя.

## 5. Первоисточники, проверенные для следующего выпуска

- Mayer, Davis & Schoorman. [An Integrative Model of Organizational Trust](https://doi.org/10.5465/amr.1995.9508080335), Academy of Management Review (1995). Модель доверия и риска, не оценка конкретного партнёра.
- Granovetter. [The Strength of Weak Ties](https://doi.org/10.1086/225469), American Journal of Sociology (1973). Теоретические связи между социальными кругами, не инструкция «набирать контакты».
- Dunlosky et al. [Improving Students' Learning With Effective Learning Techniques](https://pubmed.ncbi.nlm.nih.gov/26173288/) (2013). Обзор способов обучения.
- Cepeda et al. [Distributed practice in verbal recall tasks](https://pubmed.ncbi.nlm.nih.gov/16719566/) (2006). Обзор распределённой практики. Не валидирует автоматически выбранные на сайте интервалы.

Библиография проверена 15.11.2026 по издательским и исследовательским записям. Эти ссылки **не означают независимую проверку всей исходной книги**.

## 6. Что не сделано даже в v1.2

- Полная расшифровка аудиокниги с таймкодами.
- Облачные аккаунты, реальный закрытый доступ, синхронизация между устройствами.
- Автоматическая предметная оценка открытого текста.
- Серверный ИИ-преподаватель и управляемые инструментальные агенты.
- Проверка всех культурных, исторических и бизнес-обобщений из конспекта.

**Приватность:** сайт и код публичны. `noindex` помогает не попадать в поиск, но **не защищает** контент от владельца ссылки; личные ответы находятся только в локальном браузере.
